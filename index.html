01 / 电子设计与视觉测量

2026.07—2026.08

视觉反馈的李萨如图形显示控制装置

核心成员 · 全国大学生电子设计竞赛 F 题

项目目标
在示波器 X-Y 模式下，X 通道接入未知正弦信号，Y 通道接入装置输出信号。通过非接触视觉测量获得频率和相位差，再控制输出信号生成直线、圆形和“∞”形李萨如图形。
系统方案
以 Orange Pi 处理摄像头采集的示波器图像，由 STM32F407 控制 DDS 芯片 AD9959。视觉端通过 UART 反馈频差和相差，形成图像测量与信号输出之间的闭环。
我的工作
负责图像测量算法和软硬件联调，参与闭环控制架构设计。利用短锯齿扫描与轨迹峰距法进行粗测频，通过候选频点精搜完成同步，并结合直线、椭圆和双分支模型估计相位差。
实现结果
完成目标图形的自动识别与显示控制，项目获得全国大学生电子设计竞赛省级二等奖。
技术实现与调试难点
  1. 先粗测频：利用周期已知的锯齿波，将时间映射为屏幕纵向位置，根据有效扫描高度与同侧峰距换算信号周期数，估算 1 kHz～100 kHz 范围内的频率。
  2. 再精搜同步：以粗测结果为中心，在 ±2 kHz 范围内按 100 Hz 步进搜索候选频率，根据图形稳定程度选择同步频点，减少全频段逐点搜索的耗时。
  3. 最后测相与控制：提取图形轮廓，利用 SVD 拟合椭圆参数并计算相位差。STM32 根据反馈调整 AD9959 的频率字和相位字；同频同相生成直线，同频正交并匹配显示幅度生成圆，二倍频配合相位控制生成“∞”形。

调试中关注图像噪声、测量稳定性与锁相响应时间。现阶段系统鲁棒性仍有改进空间，部分情况下存在锁相超时。

STM32F407 / AD9959 / Orange Pi / UART / 计算机视觉

02 / 嵌入式控制

2026.03—2026.05

二轮自平衡车组合导航控制系统

核心开发者 · 姿态估计与控制调试

项目目标
在不使用摄像头视觉反馈的条件下，使二轮小车保持直立，并沿指定闭合轨迹自主循迹。行驶与转弯过程中需要同时维持车身平衡、速度和方向。
系统方案
融合 MPU6050 六轴惯性传感器、编码器与灰度传感器数据，建立姿态估计、直立控制、速度控制和转向控制模块，并通过上位机观察运行状态与调节参数。
我的工作
参与小车硬件结构、电机驱动与姿态解算模块开发，主要负责多源传感器数据融合、卡尔曼滤波优化和 PID 调试，完成 UART、I²C 接口及数据遥测联调。
实现结果
实现小车稳定平衡、闭环循迹和自主行驶。
技术实现与调试难点
  1. 姿态估计：融合加速度计与陀螺仪信息，优化卡尔曼滤波以降低陀螺仪长时间积分漂移对车身倾角估计的影响。
  2. 控制环协同：直立环保持平衡，速度环通过调整目标倾角控制前进速度，转向环根据轨迹偏差调节左右轮差速。先整定直立环，再调试速度与转向控制。
  3. 数据与参数调试：通过上位机遥测观察姿态和运行数据，实时调整控制参数。重点处理多源传感器采样时序配合，以及出弯后进入直行段时的方向修正。

MPU6050 / 编码器 / 灰度传感器 / 卡尔曼滤波 / PID

03 / 无线通信与上位机

2026.06—2026.07

微型无中心自组网络

项目成员 · 通信系统综合设计与实践

项目目标
搭建无固定中心节点的 LoRa 对等通信系统，实现节点自主入退网、在线状态维护、单播与广播文本通信、温湿度数据采集和远程设备控制。
系统方案
基于 ESP8266 与 LoRa 模块，使用 Arduino 开发节点程序。LabVIEW 负责管理、显示和生成串口命令，节点解析命令并进行无线收发，再将状态、传感器数据和执行结果回传上位机。
我的工作
开发 LabVIEW 上位机，采用生产者–消费者架构组织界面事件、VISA 串口收发与协议解析；参与二进制协议设计，实现半帧组帧、校验和、异常重同步及长文本分片重组。
实现结果
实现多节点文本收发、在线状态可视化、传感器数据监测与彩灯远程控制。
技术实现与调试难点
  1. 节点状态维护：通过节点 ID 区分通信对象，结合入退网消息和心跳报告维护在线状态，各节点可主动发起通信。
  2. 协议与可靠传输：数据帧包含帧头、类型、源与目标 ID、序号、长度、载荷和校验和。对长文本进行分片编号与接收端重组，结合 ACK、退避与超时重传应对弱链路下的丢包。
  3. 上位机解耦：用事件结构与命令队列协调操作，缓存不完整串口帧并校验解析结果，出现异常时重新寻找帧头，实时展示节点、日志和传感器数据。

ESP8266 / LoRa / Arduino / LabVIEW / VISA / 串口协议
