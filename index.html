01 / 电子设计与视觉测量

2026.07—2026.08

视觉反馈的李萨如图形显示控制装置

核心开发者 · 全国大学生电子设计竞赛 F 题

项目目标
基于 STM32F407、AD9959 与 Orange Pi，对未知正弦信号进行非接触测频测相，并自动生成指定的李萨如图形。
我的工作
参与视觉测量与底层闭环控制设计；利用短锯齿扫描和图像特征进行测频，结合数学模型估计相位，并通过 UART 反馈调整输出信号。
实现结果
完成直线、圆形和“∞”形图形的自动生成与稳定显示，获得省级二等奖。

STM32F407 / AD9959 / Orange Pi / UART / 计算机视觉

02 / 嵌入式控制

2026.03—2026.05

二轮自平衡车组合导航控制系统

核心开发者 · 姿态估计与控制调试

项目目标
在没有视觉反馈的条件下，使二轮小车保持直立，并沿指定闭合轨迹自主循迹。
我的工作
融合 MPU6050、编码器与灰度传感器数据，优化姿态估计，并参与电机驱动、三环级联 PID 控制及上位机实时调参。
实现结果
实现小车稳定平衡、闭环循迹和自主行驶。

MPU6050 / 编码器 / 灰度传感器 / 卡尔曼滤波 / PID
